# Getting Started

Use this sequence after creating a repository from the template.

## 1. Fill the Core Team Notes

Update the root notes first:

- `Team Conventions.md`
- `Team Definition of Done.md`
- `Terms and Abbreviations.md`

Then add folder-based context as needed:

- notes under `Team/` for team identity and organization
- notes under `Rules/` for mandatory rules
- `Projects/Conventions.md` for project and repository conventions
- notes under `Company/` for organization context
- notes under `Customers/` for stakeholder and customer context

## 2. Shape the Ownership Model

Adjust the `Responsibilities/` folder so it matches your real team structure.

You can add, rename, or remove responsibility-area folders as needed.

## 3. Add Real Working Notes

Start adding:

- projects
- plans
- decisions
- meetings
- history entries

## 4. Keep Linking Consistent

In the repository notes, use Obsidian-style links between related notes so the context stays navigable.
