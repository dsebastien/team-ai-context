# Customization Guide

This template is intentionally generic.

Customize it by replacing placeholders and removing sections your team does not need.

## Common Customizations

- rename responsibility areas
- adjust folder structure
- remove repository tracking if your team does not need it
- add process-specific folders
- add more guidance in team rules and conventions
- replace empty placeholder folders with real content only when needed
- add organization notes under `Company/` only if they help explain the team context
- add stakeholder notes under `Customers/` only if they help guide the team's work

## Good Practices

- keep note names explicit
- keep one main topic per note
- link related notes consistently
- remove placeholder text once real content exists
- prefer `.gitkeep` in empty folders over duplicate explanatory notes

## Publishing Readiness

Before making the repository public:

- remove internal names and URLs
- confirm the `LICENSE` line
- review docs site placeholders
- review `.mcp.json` placeholders
