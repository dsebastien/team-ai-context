# Team Context Template

This site explains how to use the Team Context Template repository.

The template helps teams document who they are, what they own, how they work, and how they track projects, goals, achievements, decisions, plans, meetings, and history.

## What You Will Find Here

- a quick start guide
- an explanation of the repository structure
- note guidance for the main note types
- guidance on sharing tooling and keeping secrets out of the repository
- guidance for customizing the template
